# App 與正式網頁的功能對齊

2026-11-26。使用者要求 App 功能、欄位順序與操作完整比照 `https://lad-pocket.vercel.app`，並選擇保留 App 的「02A 霧光星軌」外觀。此次只修改 Expo 原生與 Web renderer；原作 HTML 正式站維持現況，沒有新增公告。

## 對照來源

正式站對應原作提交 `3b92e11e3c8a8e113e335ba388eef3a1d0f70bb1`。查核時正式站回應 HTTP 200，`index.html` SHA-256 為 `c7b0845156bd96e156d37319ac6ee497004b0f2f81d367ff4197378ecfb822d2`，與本機隔離 checkout 相同。瀏覽器以該來源的獨立本機站台作互動對照，避免在正式網站寫入測試紀錄。

霧光漸層、卡片高光、內外陰影、字體與星軌保留。舊視覺文件中的主要欄位收合、僅顯示最近三筆等安排已取消，後續功能布局以本文件及使用者最新指示為準。

## 計算與動畫修正

- 原本主畫面的「目標後剩餘鑽」取自購買前資源。改用已選禮包的結算結果，包含手動調整包數後的鑽石餘額，與正式網頁一致。
- 原生預留抽數與編輯金額保留輸入中的小數文字，到更新／儲存時才使用數值，避免輸入小數點即被重設。
- 頁面切換淡入 350ms、預算進度條 500ms、明細／視窗淡入約 180ms。排期既有漸入保留；系統「減少動態效果」生效時停止相關動畫或立即完成。視窗底色保持可讀，不透出底下的表單文字。
- Web 編輯視窗掛載於 body，避免頁面轉場 transform 改變固定視窗定位；新增相容 React 19.2 的 `@types/react-dom` 開發型別，未增加執行時依賴。

## 驗證

瀏覽器使用 Ego Lite，以 `127.0.0.1:8084` 的 App 和 `127.0.0.1:8096` 的原作來源對照，與使用者的 `localhost:8081` 資料隔離。

- 10 組不同卡池／資源／目標案例，對照差額鑽石、課金抽數、剩餘鑽石、官方券、建議包數與總價；結果一致。
- 7 種活動卡池 × 3 幣別，共 21 組禮包建議、總價、包數與剩餘鑽石對照通過。另測手動官方券 0、卡池切換及重新整理保存、恢復自動、預留單位轉換、手動改包數及重設。
- 禮包帶入錢包；新增 MYR802、改為 MYR42、預算剩餘額連動、重新開啟保存；幣別隔離、月份切換、期間統計與圖表月份選取通過。CSV 包含日期、金額、幣別、類別及備註。
- 編輯視窗取消／Escape、焦點循環、刪除確認取消／確定、刪除復原通過。測試新增的 App 花費已移除。
- 11／12 月活動清單、角色篩選及 12/14 單日清單與原作一致；整月返回、預測虛線、行事曆匯出及排期帶入規劃通過。12 月 ICS 含 7 個活動。
- 換算、錢包、排期在 320／390／1024px 共 9 組版面均無頁面水平溢出；底部五個入口最窄仍各有 48px 寬。另檢視 320px 編輯視窗，內容完整位於畫面內且可捲動。
- 檢查一般及減少動態效果的 CSS，頁面動畫與進度條轉場隨設定調整。回饋入口、問卷／Threads 目的地及追蹤畫面可載入，未送出測試問卷。
- `npm run check`：ESLint、TypeScript、15 項 Node 及 224 項 Vitest 測試通過。
- `npm run verify:ios-bundle`：8.5 MiB Hermes iOS 匯出通過。
- `npm run export:web`、`npm run verify:web`：24 項發行檔案、33 個預快取 bundle、5.7 MiB 匯出通過。

完整本機記錄、對照 JSON、CSV／ICS 與截圖位於受忽略的 `.agent-local/web-parity-*`、`.agent-local/parity-*`。這些是開發驗證證據，不上傳使用者資料。

## 預覽與手機狀態

App 預覽為 `http://localhost:8081/calculator`；停止預覽後可用父資料夾的 `預覽App.command` 或 `npm run preview` 重啟。

本機尚無可用 iPhone Simulator。原生 renderer 已修改並通過型別及 Hermes 編譯，但日期、鍵盤、系統分享、安全區域、大字級與動畫仍須實機驗收。不能把 Web 截圖稱為原生實機結果。

既有 TestFlight 1.0.0（8）及已建置但上傳失敗的 1.0.1（9）均不含這次功能對齊。待 Account Holder 處理 Apple 協議後，需以最新提交重新建置並上傳，另記錄群組可用及實際安裝狀態。此次沒有新增雲端建置、上傳 TestFlight 或部署正式網站。
