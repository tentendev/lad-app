# 02A 參考圖重合修正

2026-11-13。以 Maggie 本次貼上的 [02A 霧光星軌・原版](../artifacts/2026-11-13-02a-fidelity/reference.png) 重新對照；範圍是 App 的原生介面與 App Web renderer，原作 HTML 網頁版維持現況。會員連線等待 Clerk 權限，本次沒有修改服務設定、資料庫或發布版本。

## 具體修正

- 材質：白色邊緣高光、內側亮邊、下緣淡紫陰影與柔和外陰影一起保留；卡片與輸入框有各自的深度。原生使用可實際繪製的 SVG 漸層，不用純色代替；主按鈕與選中的分頁也有漸層。
- 背景：重新繪製分層霧光、頁首交疊的半透明波帶、細星軌與光點。使用向量與程式碼，不把設計圖當成介面截圖或整張背景。
- 頁首與分頁：品牌靠左，通知與設定入口靠右；四個主要分頁的圖示、淡紫選中背景、圓角和上緣高光依參考圖調整。意見回饋保留在頁尾入口，沒有刪除問卷功能。
- 錢包：月份、環形預算、鑽石／限定券列、新增花費與最近三筆紀錄放在首頁。新增花費、完整紀錄／匯出、預算幣別設定及統計可展開；換算帶入花費時會自動開啟表單。資源列讀取裝置上實際的換算設定，不寫入或重設換算資料。
- 換算：將鑽石／限定券輸入、可抽與目標對照、進度、差額及更新規劃放在最前面。卡池、目標、官方券、預留資源與保底說明保留在同頁設定內；結果仍使用原本的計算邏輯，官方券與預留生效時會加註。
- 排期：預設顯示參考圖的圓點月曆、六個男主篩選與獨立活動卡。日期的圓點來自真實排期；點選後仍能看當日活動，展開活動卡後可看來源、加入行事曆或規劃。完整色條月曆、圖例、來源資訊與匯出仍可切換查看。
- 文字：主要介面的標題、標籤與數字更貼近參考圖的明體與襯線層級，保留原生字級縮放、鍵盤避讓與大數字的換行。
