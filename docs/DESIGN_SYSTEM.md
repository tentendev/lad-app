# 深空省省設計基準

本專案以 2026-08-13 原始版畫面為設計權威。新功能必須延伸既有語言，不新增另一套視覺品牌。

## 核心視覺

- 背景：淡藍紫星空，頁面底色 `#7765A7`。背景只提供氣氛，不可影響文字可讀性。
- 卡片：深紫 `#493B70` 半透明玻璃，白色 28–55% 邊線，圓角 20px，柔和模糊而非厚重陰影。
- 導覽：固定於底部，底色 `#60487F`，啟用項目純白，未啟用項目白色 58%。
- 文字：標題使用宋體／襯線感，操作文字使用繁體中文系統黑體；主文白色，次要文字白色 60–82%。
- 版面：單欄、手機優先，Web 與 iOS 內容最大寬度皆為 520px；第一張功能卡直接出現在頁首，不另外加入大型品牌 Hero。

## 互動與細節

- 所有可點擊區至少 44px；月份左右切換使用 1px 白框方形按鈕。
- 選取日期使用白框與淡白底；今天只增加清楚輪廓，不覆蓋活動色。
- 表單使用玻璃底與淡白邊框；錯誤訊息就地顯示，儲存失敗不可清空輸入。
- 刪除花費後提供「復原」，避免只靠破壞性確認視窗。
- 底部導覽始終維持「錢包／排期／換算／追蹤」四項與相同圖示順序。
- Web 與 iOS 共享 `src/theme/tokens.ts` 的原生色值；Web 對應值集中在 `src/web.css` 的 `:root`。

## 發版前視覺檢查

1. 320px、390px、520px 與 1024px 四種寬度無水平捲動。
2. 排期色條跨週時正確分段，文字不遮住日期。
3. 五位男主可個別切換，全部選取狀態清楚。
4. 底部導覽不遮住最後一筆內容，並包含安全區高度。
5. 背景失效時仍有 `#7765A7` 底色，文字對比仍可讀。
