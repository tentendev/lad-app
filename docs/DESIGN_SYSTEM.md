# 深空省省 App 設計基準

2026-11-12 選定「02A 霧光星軌・原版」，以 [已選定參考](../artifacts/2026-11-13-02a-fidelity/reference.png) 為準。02B「星軌編輯室」不是此次採用版本。App 介面獨立維護；HTML 網頁版維持現況，僅排期更新時同步兩版排期及獲准的排期公告。

卡片使用接近不透明的白色與淡紫色，保留細邊線與柔和陰影。星軌與霧光由原創 SVG／漸層構成，放在內容後方，不承載資訊也不攔截操作。主要與次要文字、語意色均以珍珠白底達到 4.5:1 以上為基準。

## 字體與版面

- 標題：Web 使用 Noto Serif TC；iOS 使用 Songti TC；Android 使用系統 serif。
- 數字：Web 使用 Baskerville／Times New Roman；iOS 使用 Baskerville；其餘採可用的系統襯線數字。
- 主要介面的標籤與操作延續參考圖的明體；長說明保持清楚易讀，原生保留 Dynamic Type，不靠縮小字體擠入固定高度。
- 頁首採左側品牌與右側通知／會員入口。錢包、換算、追蹤與會員中心各有短標題。
- Web 手機內容最大寬度 520px；寬螢幕與原生平板沿用適合表單、排期與資料的多欄；管理後台可展開至 1100px。
- 卡片約 18–20px 圓角，控制項約 12–16px，主按鈕約 24px；控制項至少 44px，原生主要操作至少 48px。

## 功能視覺

- 錢包：左側預算與已花，右側環形剩餘預算；未設定與超支皆有文字，不單靠環形與顏色表達。
- 排期：預設為圓點月曆與六個篩選按鈕，活動卡保留官方／預測區別；可切換完整跨週色條、圖例與來源。色條使用深色文字，預測另有虛線。
- 換算：保留資源、官方券、預留與禮包的功能層級，卡池選單僅提供七種活動池。
- 追蹤：三條計數線、保證校正、五星表單與統計採一致的淡紫分組，資料不因換膚而重設。
- 會員：登入、註冊、驗證碼、忘記密碼、個人資料、備份與刪帳使用相同卡片語言。
- 管理後台：會員搜尋、分頁、狀態、備份時間與管理紀錄。操作彈窗必須確認對象並填寫原因；不提供玩家財務或抽卡明細瀏覽。

男主與活動的語意色繼續定義於 `src/theme/tokens.ts`；周邊色為 `#B8DF78`。裝飾色與語意色用途分開，避免改版造成活動分類意義改變。

## 維護與驗證

原生 token 位於 `src/theme/tokens.ts`、`src/native.css`；Web 位於 `src/web.css`。背景分別為 `OrbitBackdrop.tsx` 與 `public/pearl-orbits.svg`，不使用提案圖片作為介面截圖或背景。

改版前的 Git 備份分支為 `backup/20261112-before-02a-membership`（`0d62224`）；原始碼 ZIP 及原畫面位於父資料夾 `備份/App-2026-11-12-改版前/`。

檢查窄螢幕、桌面、長文字、空值、超支、表單錯誤、彈窗與底部安全區。Web 的瀏覽器驗證與 Hermes 匯出不能取代原生實機的鍵盤、日期、安全區域、動態字級與 Apple 登入驗收。

2026-11-13 的材質與版面修正見 [參考圖重合紀錄](02A_REFERENCE_FIDELITY.md)：不可省略白色高光、內陰影、外陰影、按鈕及分頁的漸層。手機首頁依參考圖維持精簡資訊順序，進階功能保留在展開入口。
