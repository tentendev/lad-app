# App 視覺對齊驗證（2026-11-11）

參考為網頁版 `0f0ed71` 的 `index.html`；App 修改基於本機 `4fa519c`。本次只調整 App，未修改網頁版程式或四份共用排期／公告／價格來源。

## 完成內容

- Web 與原生共用原網頁的星空背景、半透明紫色卡片、白色細框與圓角；標題與數字沿用襯線風格。Web 載入與原網頁相同的三組 Google Fonts，原生採系統襯線字體。
- 原生頁首改為置中線稿品牌，移除額外的大分頁標題；兩端保留公告、會員入口、五個主要分頁及追蹤／規劃功能。
- 錢包的幣別選擇與可展開的預算設定移入預算卡片，支出洞察置於花費紀錄後；原生幣別選擇從只出現在載入階段修正為可在正式畫面操作。
- 換算輸入與結果集中在同一張卡片，修正同列輸入欄位被說明文字撐高的情況；記帳日期與備註使用完整一列。
- 原生卡池、禮包幣別與新增花費類別使用可捲動的選擇清單，保留系統日期選擇、鍵盤避讓、安全區域、字級縮放與 48pt 主要觸控範圍。
- 診斷浮動按鈕改為明確設定 `EXPO_PUBLIC_ENABLE_DEBUG_TOOLS=true` 才顯示。

## 驗證

- `npm run check`：ESLint、TypeScript、15 項 Node 測試、129 項 Vitest 測試通過。
- `npm run verify:ios-bundle`：iOS Hermes bundle 與新背景資產驗證，總匯出約 8.6 MiB。
- Android Expo export：Hermes bundle 約 8.7 MB，包含新背景與原生選擇清單。
- 瀏覽器四個主要分頁在 320／390／1280px 無主內容水平溢出；詳見 [responsive.json](responsive.json)。
- 換算：持有 1,500 鑽、目標 70 抽、手動官方金券 0，結果為尚差 9,000 鑽／需課金 60 抽；重新整理後手動金券及結果保留。
- 禮包改為 MYR 後正確顯示 RM 售價；新增 RM4.9 花費成功，切回 TWD 不會混入該筆紀錄。
- 可展開預算設定並儲存，預算卡片立即更新。
- 測試前保存既有 `lad_` 資料；測試後還原換算、預算、花費與幣別，逐一比對原值一致，移除暫存資料。
