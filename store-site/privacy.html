適用範圍

本政策適用於深空省省 App、相關公開網站、依版本及設定啟用的會員與私人雲端備份，以及支援聯絡。聯絡信箱為 dev@tenten.co。

本機資料

未登入時，預算、花費、抽卡資源、備註、換算設定、抽卡規劃與五星紀錄只保存在你的裝置，不會自動上傳。移除 App、清除網站資料或裝置故障可能使資料消失。

會員與驗證

啟用會員功能時，Clerk 代表我們處理姓名、Email、使用者識別碼、登入憑證與驗證狀態。社群登入只在該版本已啟用及你主動選擇時使用。Clerk、Vercel 或其基礎設施可能為登入、安全與防止濫用處理 IP、裝置／瀏覽器資訊及必要請求紀錄。App 已關閉 Clerk SDK telemetry。

私人雲端備份

只有你主動點選上傳時，預算、花費、抽卡資源、備註、換算設定、抽卡規劃與五星紀錄才會經 Vercel API 儲存到 Neon，以 Clerk 使用者識別碼隔離。系統不會自動存取其他 App、付款卡、銀行帳戶或遊戲帳號。

目的與分享

資料用於提供及保護會員、驗證登入、你主動選擇的備份／還原、處理版本衝突、支援回覆及必要法律或安全義務。我們不出售個人資料，App 不含廣告 SDK，也不做跨 App 廣告追蹤。

服務供應商可能在其他國家或地區處理資料。相關政策：Clerk、Vercel、Neon。

保留與刪除

本機資料保留到你移除 App 或清除資料。雲端備份保留到你覆寫、單獨刪除備份或永久刪除帳號。會員中心可只刪除 Neon 備份，或永久刪除備份與 Clerk 會員；這些操作保留本機資料。服務供應商可能依備援、安全或法律義務保留必要紀錄。

Apple 登入會員刪除帳號時，系統會嘗試撤銷 Apple token；若無可撤銷 token，仍會完成會員及雲端資料刪除，並提供 Apple ID 設定中的手動撤銷路徑。

安全與你的選擇

登入 token 在 iOS 使用 SecureStore；API 驗證 Clerk token，依使用者識別碼隔離資料，傳輸使用 HTTPS。你可以不登入使用主要功能，也可在會員中心修改資料、主動備份／還原、刪除雲端備份、登出或永久刪除帳號。

存取、更正、刪除或限制處理等要求，若無法在 App 內完成，可寄至支援信箱。寄送支援信時，信箱供應商會處理你的 Email、信件及附件，以便回覆。

兒少與政策變更

本服務不是專為 13 歲以下兒童設計，不會故意向其收集會員資料。得知不符規定的兒少資料時，會採取刪除措施。政策重大變更會更新本頁日期，必要時在 App 提供通知。
