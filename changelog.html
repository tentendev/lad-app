Current release v0.2.1 · Debug quick access

版本命名規則

版本格式為 MAJOR.MINOR.PATCH；目前仍在 v0 Early Access，不輕易升大版本。

SemVer
v1.0.0 MAJOR · 重大發布 核心產品範圍、資料模型或使用方式有重大改變。原則上至少累積 30+ merged PR，並通過 release review，才考慮升版。
v0.3.0 MINOR · 新功能 向後相容的新能力或明顯體驗改進，收納在目前的大版本之下；每一筆小版本 Log 預設收合。
v0.2.1 PATCH · 修正 向後相容的 bug、資料或文字修正，不增加主要使用流程，也不藉此包裝重大變更。

#v0-2-1
v0.2.0 Internal product operationsRoadmap、URL Index 與版本交接基礎 2026-08-13 3 Added2 Changed

Added

  • 新增 Features Roadmap：專案盤點、IRCE 自動排序、篩選與可保存的驗收清單。
  • 新增 URL Index：列出頁面與 runtime assets，支援同網域 health check、搜尋與複製。
  • 新增本 Changelog 頁與可複製的 GitHub release template。

Changed

  • 建立 Roadmap → URL Index → Changelog 的輕量內部資訊架構，不套用正式站 header／footer。
  • 建立共用 internal.css，統一 compact table、filter、status、focus 與 responsive 行為。

Known

  • Roadmap 勾選狀態只儲存在目前瀏覽器，不會同步 GitHub 或其他裝置。
  • URL inventory 仍需在新增或刪除檔案時由同一個 PR 手動更新。
#v0-2-0
v0.1.0 Repository baseline可操作的抽卡與課金規劃 MVP 2026-08-13 7 Added3 Known

Added

  • 排期月曆、跨日活動顯示、官方／預測註記與日期明細。
  • 鑽石、金券、官方返券、目標抽數與預留資源即時換算。
  • 禮包階級比較、推薦方案、累計總額與帶入錢包記帳。
  • 每月預算、提醒門檻與花費新增／編輯／刪除。
  • localStorage 儲存與舊分類資料 migration。
  • 產品定位、Journey、Persona、JTBD 與 UX Research 文件。
  • 保留 0804.html 作為舊版 regression snapshot。

Changed

  • 從「深空帳本」收斂為「深空省省」，聚焦抽卡與課金決策，而非一般記帳。
  • 把禮包建議與錢包串接，減少完成購買後的重複輸入。

Known

  • 排期與禮包資料由 JavaScript 人工維護，尚無逐筆來源與自動過期。
  • 玩家資料只存在單一瀏覽器，清除 storage 後無法復原。
  • 尚未建立自動化測試、產品 analytics、登入同步與完整 PWA。

每次更新的最低交接內容

同一個 PR 若改變使用者可見行為，必須新增一筆版本內容；不要只寫「UI update」或「bug fixes」。

## v0.x.y — Release title
Date: YYYY-MM-DD
PRs: #123, #124

### Added
- 新增了什麼，以及使用者現在能完成什麼。

### Changed
- 哪個既有行為改變，以及為什麼。

### Fixed
- 原本的問題、影響範圍與修正結果。

### Known
- 尚未解決的限制、風險與下一個動作。
