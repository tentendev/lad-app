React Native Reusables：我最推薦 LAD 使用 **核心概念：shadcn/ui for React Native。** 官方自己就是這樣定位：把 shadcn/ui 的模式帶到 React Native，使用 NativeWind / Uniwind，並明確包含 Expo、React Native Web。([GitHub][2]) 它最大的優勢不是「元件很多」，而是： **元件程式碼直接屬於你的 Project。** 不是： ```tsx import { Button } from "some-ui-library" ``` 然後所有 UI 被 library API 綁死。 而更接近 shadcn： ```text components/ ├── ui/ │ ├── button.tsx │ ├── card.tsx │ ├── dialog.tsx │ ├── input.tsx │ ├── select.tsx │ ├── tabs.tsx │ └── progress.tsx ``` Agent 可以直接讀、改、重構這些 component。 這對 Full-Agentic Coding 特別重要。 ### LAD 現在的元件幾乎可以直接 mapping | LAD UI | React Native Reusables | | ---------------- | ----------------------- | | 本月預算 | Card + Progress | | 每月預算設定 | Input | | 提醒門檻 | Input / Slider | | 記一筆花費 | Input + Select + Button | | 類別 | Select | | 編輯花費 | Dialog / Bottom Sheet | | 排期 | 自訂 Calendar | | 抽卡類型 | Select / Tabs | | 抽數 / 鑽石 | Toggle / Tabs | | 計算明細 | Collapsible | | 底部「錢包 / 排期 / 換算」 | Expo Router Tabs | GitHub Repo 本身也標記 Expo、React Native Web、Radix UI、shadcn 等相關技術。([GitHub][2]) ### 最大優勢 **你現在 LAD 的視覺可以保留。** 不需要把 LAD 改成 Material Design，也不需要變成某一個 UI Kit 的既定風格。 這點對你的 App 很重要。 --- # 2. gluestack-ui v5：Agentic Coding 最值得關注 如果純粹從 **2026 年新專案 + Expo + AI Agent** 的角度，我認為 gluestack-ui v5 已經非常接近 React Native Reusables。 目前 v5 已經改成： > copy-paste components + Tailwind CSS / NativeWind 而不是以前 NativeBase 那種傳統 component dependency 模式。官方目前明確標示支援 NativeWind v5 / Tailwind v4、Expo Router First、CLI 加 component、theming 與 accessibility。([GitHub][3]) 例如： ```bash npx gluestack-ui init ``` 再由 CLI 加： ```text Button Input Card Modal BottomSheet Select Tabs Accordion Avatar Badge Progress Toast Menu Popover ``` 官方目前已有 30+ responsive components，而且還包含 Bottom Sheet、Image Viewer 等比較 App-oriented 的 component。([gluestack][4]) 更值得注意的是它目前的 Repo 本身甚至已經有： ```text .agents/skills/ CLAUDE.md ONBOARDING.md ``` 而且官方 repo 已經超過 16,000 commits。([GitHub][3]) 這代表它目前明顯正在往 AI/Agent-assisted development 的 workflow 靠。 ### 對 LAD 的優點 如果之後要增加： ```text Community Profile Comments Notifications Settings Feed User-generated content Avatar Bottom Sheet Toast Image Viewer Action Sheet ``` gluestack 已經有很多現成 Pattern。 因此： **現在是工具 App，但很確定未來要做 Community：gluestack 很有吸引力。** --- # Tamagui：技術架構最完整 Tamagui 是這批裡面最成熟的 Universal Design System 之一，目前約 **14.1k stars**。([GitHub][5]) 它真正強的不是 component，而是： ```text React ↓ Tamagui ↓ Web ─ React Native ↓ iOS / Android ``` 官方目標就是 Web / React Native 共用同一套 UI，並透過 compiler 對 Web 產生 CSS、對 Native 產生 optimized View/style。([GitHub][5]) 所以如果目標是： ```text lad-app.com + iOS App + Android App ``` 而且希望 UI code sharing 最大化，Tamagui 非常強。 ### 但我沒有把它排第一 因為它有自己的： ```text tokens themes styled() variants compiler configuration ``` 例如 Agent 必須理解： ```tsx
